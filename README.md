1. 🌳 Planta o Destruye
   - Van apareciendo botones: 🌱 plantar / 🪓 talar.
   - Tienes 30 segundos para conseguir que haya más árboles que antes.
   - Si talas demasiados, pierdes.
   - Fácil con un contador y botones.
2. 🗑️ Basura a la Papelera
   - Caen objetos desde arriba: 🍌, 🥫, 📄, 🔋, 🍾...
   - Tienes que arrastrarlos a su contenedor correcto.
   - Cada error resta puntos.
   - Tipo mini sorting game.
3. 🚿 ¡Cierra el Grifo!
   - Un grifo pierde agua constantemente.
   - Tienes que hacer clic para cerrarlo antes de que se llene un depósito.
   - Cada cierto tiempo se vuelve más rápido.
   - Puntuación = litros ahorrados.
4. 💡 Apaga las Luces
   - Una casa con 10 habitaciones.
   - Las luces se van encendiendo aleatoriamente.
   - Tienes que hacer clic en ellas para apagarlas.
   - Si dejas demasiadas encendidas, pierdes.
5. 🐟 Salva al Pez
   - Un pez está nadando por un río lleno de basura.
   - Mueves al pez con ← → y tienes que esquivar botellas, latas, bolsas...
   - Cuanto más sobrevives, más puntos.
   - Básicamente un Flappy Bird cutre pero horizontal.
6. 🚲 ¿Cómo vas hoy?
   - Aparecen diferentes transportes: 🚗 🚌 🚲 🚶 🚆.
   - Tienes que elegir el transporte más sostenible para cada situación.
   - Ejemplo: "Ir a comprar pan a 500 metros" → 🚶.
   - Cuanto menos CO₂ generes, mayor puntuación.
7. 🔥 Apaga el Incendio
   - Aparecen pequeños incendios en un bosque.
   - Tienes que hacer clic sobre ellos para apagarlos.
   - Pero también aparecen animales 🦌🐇 que NO debes clicar.
   - Cada ronda aparecen más cosas.
8. 🥤 El vaso equivocado
   - Te aparecen objetos para tirar: botella, lata, vaso, pajita, cartón...
   - Tienes que decidir rápidamente: reutilizar / reciclar / basura.
   - Algunas cosas tienen respuestas bastante troll.
   - Ideal para hacerlo con botones.
9. 🌍 No rompas el planeta
   - Tienes una barra de "Salud del planeta: 100%".
   - Cada ronda eliges entre dos acciones:
     - "Usar coche" / "Ir andando"
     - "Ducha 20 min" / "Ducha 5 min"
     - "Comprar nuevo" / "Reparar"
   - Tus decisiones van modificando la barra.
   - Al final aparece un resultado absurdo tipo: "Has salvado 3,2 planetas."
10. 🦆 El pato reciclador
    - Un pato 🦆 camina por un parque.
    - Tienes que hacer clic en toda la basura antes de que el pato llegue a ella.
    - Si el pato pisa basura → pierdes una vida.
    - Si recoges todo → "El pato está orgulloso de ti."
11. 🌱 Jardín Express
    - Tienes 60 segundos.
    - Puedes plantar árboles, flores y arbustos.
    - Cada planta necesita cierta cantidad de agua.
    - Tienes un depósito limitado.
    - El objetivo es conseguir la mayor biodiversidad posible sin gastar toda el agua.
12. ♻️ Sostenibilidad a lo bruto
    - Juego de preguntas rápidas.
    - Aparece una situación y tienes 3 segundos para elegir.
    - "Una camiseta rota: ¿qué haces?"
      - A) Tirarla
      - B) Repararla
      - C) Quemarla
    - Las preguntas se vuelven cada vez más absurdas.
    - Puedes meter un contador de racha: 🔥 "12 decisiones sostenibles seguidas".
